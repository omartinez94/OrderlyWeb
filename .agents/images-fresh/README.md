## Usage Guide

These assets are prepared for local testing, presentation, and showcase pages:
- Use `01-welcome-hero.jpg` on welcome screens or onboarding wizards.
- Use `01-empty-orders-queue.jpg` for empty state placeholders when no orders are present.
- Use `01-all-caught-up.jpg` when all orders/tasks are completed (celebration states).
- Use `02-login-background.jpg` as the full-bleed CSS cover background for authentication screens.
- Use `02-404.jpg` and `02-maintenance.jpg` for system error and downtime displays.
- Use `03-kds-mockup.jpg` and the `04-` feature series on feature description panels, settings, or marketing cards.
- Use `05-staff-avatar-set.jpg` to crop out individual role avatars for mock accounts.
- Use `06-ingredients.jpg` as a low-opacity textured background or card graphic.
